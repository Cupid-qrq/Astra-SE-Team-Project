# A线 P1 教学服务与页面实施计划

> **For agentic workers:** 使用 superpowers:executing-plans 逐项实施，先失败测试，再实现和验证；全分支完成后独立审查。

**Goal:** 完成可独立验证的 P1-A1—A4，实现真实 PostgreSQL 上的身份、课程、题目与作业服务及 A 所属页面，提供 B 可接入的端口。

**Architecture:** 保持模块化单体及 A/B 归属。A 模块位于 `server/app/modules`；依赖 B 的公共应用、预检、成绩和提交通过显式端口接入。B 尚未推送，A 的安装锁、验证应用、Alembic 环境放在 `server/a_line`，不创建 B 的总应用和迁移 head。验证环境使用真实 PostgreSQL，不运行学生程序。

**Tech Stack:** Python 3.12+、FastAPI、Pydantic、SQLAlchemy 2、Alembic、PostgreSQL、uv；现有 React/TS、CodeMirror 6、Vitest、Playwright。

**Spec:** [架构](../02-architecture.md)、[接口](../03-api-contract.md)、[数据](../04-data-design.md)、[界面](../05-ui-specification.md)、[阶段任务](../06-roadmap.md)。实施人 A覃锐谦；成员评审 B祝祎帆，代理独立审查不替代成员审批。

## Global Constraints

- 原规划 v0.3、A 接口契约与中文署名工作流继续生效；不修改 archive。
- 不访问收费模型；不代写 B 的评测、提交受理、成绩或管理页面。没有 B 服务时依赖动作明确不可用，不伪造完成。
- 顶层事务统一提交；应用服务不提交；领域规则不读系统时间；锁内无网络。
- 401/403/404、CSRF、Origin、账号失效、跨课程授权、revision、公开白名单投影必须在服务端验证。
- 发布版本不可变，发布要求全部语言/全部测试的匹配摘要预检证据；测试适配器的合成证据不得进入正常应用。
- B 总迁移合入、跨线端口和 I0/I1 联验保持待完成；独立验证不冒充阶段 Done。

## Task 1: P1-A1 身份、课程与真实数据库基础

**Files:** `server/app/modules/identity/{domain,application,models,api}.py`、`courses/{application,models,api}.py`；`server/a_line/{pyproject.toml,uv.lock,alembic.ini,migrations,astra_a}`；`server/tests/a_line`；前端 auth/courses。

**Interfaces:** 产生会话身份、课程读/写授权、数据库事务和审计适配端口。A 模块接收 SQLAlchemy Connection；测试入口负责 begin/commit/rollback，B 集成时复用其 UoW。管理员账号 API 不创建管理员页面。

- [ ] 写失败测试：会话轮换、15分钟/8小时边界、5次登录失败、密码重置/停用撤销、强制改密；教师建课/修改/成员授权，匿名401、错角色403、跨对象404、旧revision409。
- [ ] 运行 pytest，确认缺少实现导致失败；实现领域规则、数据库表及应用服务、HTTP适配。
- [ ] Alembic空库升级、再次升级不丢数据、约束拒绝、并发revision只有一个成功；至少30个授权案例；HTTP响应对照已发布schema。
- [ ] 登录强制改密、教师建课/成员页面接入；浏览器直连API和PostgreSQL。
- [ ] 通过格式、类型、pytest和相关浏览器检查后提交中文commit。

## Task 2: P1-A2 题目版本与预检发布

**Interfaces:** 消费课程授权，提供版本公开投影/教师内容、内容摘要与 `PreflightPort`（仅数据库查询的发布证据）。执行请求由 B 服务承担。

- [ ] 失败测试覆盖内容字节上限、配对测试连续1—10、非空参考程序、版本复制、发布后不可变、预检摘要/语言/测试覆盖不一致拒绝、不同教师/学生不可读取隐藏数据。
- [ ] 实现服务与题目维护页面，保存冲突保留输入；缺少预检适配时返回明确503。
- [ ] 运行pytest、客户端契约/类型、页面测试；合成预检仅通过测试依赖注入；提交。

## Task 3: P1-A3 作业管理、编辑器和草稿

**Interfaces:** 消费已发布版本，提供 B 受理所需作业/题目授权查询；受理与结果组件通过前端显式接口接入。课程→作业锁序；策略/延期经业务保护端口，缺少适配时失败关闭。

- [ ] 失败测试覆盖1—20题/100分、重复题目、跨课程/草稿版本、开放截止边界、开放前学生不可读题面、不可改发布内容、延期/策略revision和grade_epoch。

## Review Focus

- 并发密码重置/停用与旧会话写请求的锁序与撤销是否一致。
- 非ASCII正文、超长请求、异常JSON与错误响应不泄露源码、密码或隐藏答案。
- 伪造游标、跨教师版本ID、过期预检证据不得越过授权或发布门槛。
- 长时间编辑后身份/语言/题目切换，不串草稿、不丢代码、不重复提交。
- 依赖未接通时明确不可用；测试替身、演示账号和合成预检不得被正常启动路径激活。

## 验证与回退

计划独立审查补充（2026-10-25）：

- 预检端口包含 enqueue/read/evidence，教师页面调用B路由；证据在同一事务读取，不直接查询B内部表。
- 共享锁序为 policy_guard→课程→作业；成员变动/账号停用的计分影响经事务端口更新grade_epoch；延期与重评互斥。适配器缺失时不得静默跳过。
- A业务模块不得导入server/a_line。审计、事件和共享锁由验证适配器装配，交接列明正式共享层替换点、A实体DDL及跨线外键。
- 安全用例落实Argon2id参数、仅存令牌摘要、Cookie属性、10分钟登录失败窗口及10分钟冷却；30项跨对象测试之外增加20项脚本/事件/外链图片渲染用例。
- 敏感写操作的审计/事件失败必须连同业务修改、revision和epoch回滚；新增实体迁移须验证带数据前版→当前版升级。
- 接口测试核对实际注册路由、请求及响应schema、状态码、错误和权限语义；未实现P2/P3或跨线路由单列，不伪装完整全路由覆盖。

每项pytest先失败后通过，检查命令与结果写入本计划的忽略工作日志。完整入口 `python tools/check_runtime.py`；数据库测试缺配置须失败，不能skip。仅测试库可重建。迁移降级仅限无业务数据的独立测试库，集成时B分配正式revision并审查单head；应用回退使用前一个提交。远端分支可保留用于评审，不自动回退或改写主线。
