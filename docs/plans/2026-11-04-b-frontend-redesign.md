# B前端视觉重设计

用户授权仅重设计前端。参考洛谷的内容组织和鹰角官网的黑白、亮色点缀、图形与动效。负责人B祝祎帆，独立代理检查视觉及代码边界。沿用已批准的业务行为和现有API。

## 设计与文件范围

- 三份本机概念稿覆盖课程目录、登录、编辑器，使用黑白/黄绿、几何字标、轨道线、直角控件和清晰表格。
- styles/tokens.css统一配色、字体、比例，新增styles/studio.css承接主题，main.tsx加载。
- components/ui/Brand.tsx提供装饰字标与轨道图形，App.tsx调整导航与页头，LoginPage.tsx和CoursesPage.tsx落实主视觉。
- 其余课程、题目、学习、成绩、管理、弹窗、编辑器通过共享组件及样式统一。动效遵循减少动态设置。
- 页面文案与控件沿用已有能力，数字来自当前加载数据。

## 验证与恢复

运行前端类型、lint、格式、现有单元与适用浏览器检查。实际演示环境检查三角色桌面及390宽窄屏、登录、目录筛选、表单、源码编辑、提示浮层、弹窗与结果。对照概念截图核对排版、颜色、字号、组件、图形与留白。没有Browser插件，使用既有Playwright。

恢复时撤销本任务前端及设计记录提交即可，不涉及数据库迁移或数据恢复。
