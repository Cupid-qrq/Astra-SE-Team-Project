# 需求规格

## 1. 角色与权限

| 能力 | 学生 | 任课教师 | 管理员 |
| --- | --- | --- | --- |
| 课程与作业 | 本人有效成员课程 | 本人负责课程 | 元数据及维护 |
| 提交、代码与反馈 | 本人 | 本课程学生 | 默认不可读取业务正文 |
| 题目隐藏测试、参考程序 | 不可读取 | 本人课程 | 默认不可读取 |
| 成绩 | 本人已发布及明确标记的暂定成绩 | 本课程统计、发布、重评、导出 | 不可直接改分 |
| 账号和服务 | 本人改密 | 本人改密 | 账号管理、故障恢复、审计 |
| 应急访问 | 无 | 无 | 故障编号、范围、时限、理由和审计齐全后临时授权 |

服务端逐请求校验身份、角色、课程和对象归属。未登录返回 401；角色不足返回 403；不可见对象返回 404。管理员不自动获得任课教师权限。停用成员保留历史数据，禁止新增操作。

### 3.1 统一重评与成绩发布

重评范围在批次创建时冻结并保存数量和摘要；不能只评原 AC 或特定学生。待激活结果与当前结果分别保存。新批次未就绪时保留旧成绩快照，显示“重评中”；激活事务切换全部目标结果并生成新快照。原成绩未发布时新快照仍为暂定；已发布时生成新的已发布版本，保留旧版。

预览与创建均须验证目标版本支持冻结范围内全部历史提交语言，并使用目标版本冻结的运行环境。不兼容时拒绝创建，不能漏成员或转成永久 SE。

作业 `revision` 用于并发控制，`grade_epoch` 用于成绩有效性。仅延期重新开放、有效正式结果/作业版本变化及影响计分的成员变更推进 grade_epoch。提示策略收紧、公告与 NO_IMPACT 裁决不使原成绩失效；未决事件仍临时阻止发布并显示待处理。

活动批次期间禁止延期；确需延期时先取消未激活批次，保留其结果，再重新开放。延期后已发布成绩转为暂定，新截止后重新发布新版本。

### 3.2 公平补偿

平台容量、持久化、评测服务、严重时钟错误，以及平台积压造成的个人名额持续占满，属于应审查原因。仅违反 5 秒间隔、非法代码或个人网络失败不自动触发补偿。

事件记录开始、恢复、发现、展示、落库、恢复处理时间和影响范围；无法取得完整请求日志时允许依据监控补录并标记证据不完整。恢复后 1 个工作日内裁决，逾期告警，不能自动消除待处理状态。

确认影响正常提交机会时，按作业逐项计算：

```text
overlap = 故障区间与裁决前作业开放区间的交集时长
new_due = max(old_due, recovered_at, approved_at) + max(overlap, 10分钟)
```

相邻故障区间合并；多次独立事件分别裁决，不能重复累计同一请求或同一事件。裁决写入事件、截止、revision、公告、审计和通知事件同一事务。任何待裁决或尚未生效的补偿阻止最终成绩发布、归档及清理。

### 3.3 学习提示与练习推荐

固定帮助与模型提示独立。提示为错误类别、定位线索、检查方向、学习建议四部分，展示“建议需自行验证”；不得以完整可运行答案为输出，也不执行工具或修改业务数据。

题目家族 `canonical_problem_id` 由教师维护，同题不同版本及衍生题共享家族。推荐仅从已授权、`practice_released=true`、不在该学生任何 SCHEDULED/OPEN 作业中的家族选题；关联无法确认时排除。每题显式指定 `practice_version_id`，不随新版本发布自动切换。按标签命中数降序、problem_id 升序取前 5。推荐入口只展示该版本公开题面和样例；正式/练习提交仍必须属于已授权作业项，截止后的作业练习使用该项有效版本。首版不增加独立题库提交上下文。

模型预算沿用每日 20 元、项目累计 500 元人民币；次数、费用分别记账。接入时核实模型标识、价格、条款和 token 上限，不沿用旧价格快照作为现价。

## 5. 数据输入上限

| 对象 | 约束 |
| --- | --- |
| 登录名/显示名/密码 | 3—32 ASCII 字母数字下划线 / 1—40 Unicode 码点 / 12—128 码点 |
| 课程名/题名 | 1—100 码点 |
| 题面/样例/标签 | 题面≤32 KiB；1—3 组样例，单份输入输出≤4 KiB；最多 5 标签，每个 1—20 码点 |
| 隐藏文件/源码 | 单文件≤64 KiB；源码 1—64 KiB 且非全空白；UTF-8；隐藏文件只接受配对文本 |
| 模型上下文/返回 | 业务上下文≤24 KiB；返回同时≤2000 码点且≤8 KiB；token 上限另行限制 |
| 问题/评价/敏感操作理由 | 附加问题、评价各≤500 码点；敏感操作理由 10—500 码点 |

KiB=1024 字节，MiB=1024 KiB。码点、UTF-8 字节和 token 分别计量。题面、代码和提示作为不可信内容安全渲染，禁止原始 HTML、事件属性及自动加载外部图片。
