## 建议展示顺序

1. 以学生登录，在课程列表查看课程名称与完整课程编号，悬停按钮阅读提示；打开右上方“操作与功能说明”。
2. 打开“程序设计实践 · 秋季学期”，依次查看三项作业，确认各题内容不同。
3. 在[温度分类](https://localhost:4176/assignments/7f205573-197d-48a0-9824-f56047855381/problems/414e04f2-1690-499c-8261-68581e2a3b62)读取题意与样例，选择Python 3。先提交下面的错误程序，观察真实评测及判题帮助。

```python
print("CHECK")
```

4. 等待受理后查看提交编号、判定和资源指标。在“我的学习”查看已准备的错题记录；其他开放作业可继续完成练习。
5. 回到课程查看“练习进度榜”和“成绩榜”，第一项作业已准备100、50、0分层次。只有已发布成绩进入成绩榜；姓名显示仍可由学生按课调整。
6. 打开上述题目的讨论，查看教师置顶话题与学生回复；可继续发布自己的分析，请勿直接公开完整答案。
7. 切换教师，查看每课7名有效学生，8门课共24项作业、独立题组及已发布成绩，尝试导出成绩CSV。
8. 在判题帮助管理查看四类检查清单，在AI辅导设置查看课程要求。当前新库不运行收费模型Worker，原AI提示与费用账本保留在旧库。
9. 切换管理员，在账号管理查看新增5名学生，检查服务健康、队列、通知和操作审计。
10. 查看两门已归档Python课程，确认资料齐全且写操作显示只读说明。

## 本机环境切换

当前数据库为`astra_classroom_20261105_demo`。原`astra_course_demo`未覆盖，原提交、成绩和AI提示历史仍在原库；新库不会复制这些记录或重置原费用账本。

需查看旧记录时，在工作区执行：

```powershell
pwsh -NoProfile -File .local/switch-classroom.ps1 -Target legacy
```

返回当前教学数据：

```powershell
pwsh -NoProfile -File .local/switch-classroom.ps1 -Target teaching
```

切换脚本核对本任务登记的进程，保持访问地址不变；切换后重新登录。日常启动仍使用`tools/start_demo.ps1`读取当前本机配置。
