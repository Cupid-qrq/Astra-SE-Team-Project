# A 线教师与学生操作指南

本指南对应 A 所属身份、课程、题目、作业、编辑器和学习页面。2026-11-03核对main `674a6d3`：教师预检HTTP及独立执行Worker已合并；提交、结果、成绩、重评和管理仍在PR10候选，尚待合入与联合验收。运行部署见[运行手册](08-deployment-and-operations.md)，接线清单见[A/B 交接](a-integration-handoff.md)。

## 1. 登录与操作前准备

使用管理员分配的账号登录 `/login`。首次登录如要求修改密码，先完成修改；保存后重新登录。普通用户也可从导航“修改密码”更改本人密码。角色、课程归属、作业时间及提交正式性均由服务端判定。

教师需要有效教师账号、所属课程、可用语言环境；添加学生时需要管理员提供的学生 UUID。浏览器从管理员提供的 HTTPS 入口访问，支持 C++17 与 Python 3 单文件代码。部署密钥无需填写到网页。

“演示 · 虚构数据”表示显式 Mock 模式，只用于基础界面演示，不能证明数据库保存、真实评测或模型可用。开发用公开账号只适用于测试环境，不得用于课程部署。

## 2. 教师：课程、题目与作业

1. 在“我的课程”填写“新课程名称”，点击“创建课程”，进入新课程。课程管理中可保存名称、按 UUID 加入学生、停用或恢复成员。停用会撤销当前访问权限，历史记录仍保留。
2. 点击“管理题目”→“新建题目”，填写标题、Markdown 题目说明、公开样例、知识点标签、运行环境及来源说明，保存题面。预览仅显示安全内容，不加载外链图片。
3. 在草稿版本分别保存“配对测试”和每种允许语言的“参考程序”。测试输入及答案成对保存；发布前确认所有输入均已保存。教师维护的隐藏数据不属于学生题面。
4. 点击“启动预检”，查看该内容的排队、运行、通过或失败状态；预检通过后填写发布理由并确认发布。再次修改题面、测试或参考程序后需重新核验内容，旧内容通过不代表新内容通过。已发布版本只读，后续修改使用“复制为新版本”。持续排队时请管理员检查独立Worker；若部署缺少配置或页面明确显示服务不可用，保留草稿，不将其记为已发布。
5. 回到课程新建作业，选择已发布的题目版本，设置1—20题、正整数分值合计100分，以及北京时间的开放/截止时间和提示策略。保存草稿后填写10—500字操作理由，核对确认窗口并发布。发布后题目版本和分值不能原位修改。
6. 作业开放后可带理由“统一延期”，但不会把过去的练习提交追认为正式提交。开放后的模型提示策略只能收紧；需要允许引导提示时应在开放前确定。作业页在服务端有状态或公告时显示“公平与作业公告”，区分“公平复核中/公平复核已处理”。公平故障的裁决与统一补偿流程由 B 接入，不能用本页延期按钮代替故障裁决。

“调整练习开放策略”用于设置题目家族、明确开放的发布版本及公开状态。公开题面只暴露指定公开版本；同族开放作业的限制仍会参与提示授权。策略改变前核对受影响课程和题目，不用复制题目绕开家族限制。

另一个标签页修改题目后，重新读取会更新没有本地修改的题面；本页已有修改则保留输入，并提示尚未保存。在核对、保存前不能启动预检或发布。保存失败时先保留内容，不要通过反复点击忽略修订冲突。

## 3. 教师：固定帮助与提示模板

从课程进入“管理固定帮助”或“管理提示模板”；教师只维护自己课程，管理员在导航维护全局目录。学生没有维护权限。

固定帮助按判定及语言维护说明和检查清单。先保存草稿、预览，再填写发布理由并确认，页面保留不可变版本历史。结果使用的是该轮判定冻结的帮助版本，修改帮助不回写历史结果。

提示模板填写正文，选择正文实际使用的允许占位符，检查示例预览、保存草稿，再带理由发布新版本。运行时按课程模板优先、全局模板次之选择已明确启用的不可变版本；发布新版不会自动切换启用指针。模板发布与部署启用分别管理，发布本身不会启动收费调用。历史版本可查看，不能原位修改。

固定帮助和模板未保存编辑保留在当前标签页，按账号和目录隔离。刷新或同账号重新登录后可点击“恢复本地编辑”，仍需保存服务器草稿。关闭标签页会丢失恢复副本；存储失败时先复制内容。遇修订冲突先保留输入并重新读取，核对他人修改后再保存，不能反复强行覆盖。

## 4. 学生：阅读、草稿与提交

1. 进入“我的课程”→作业→“开始编程”，阅读题目、样例和运行限制。未开放作业不可开始；截止后页面显示练习语义；归档作业只读。
2. 在电脑选择语言并编辑代码。代码按账号、作业、题目和语言分别保存在本机浏览器，每次停止输入约500ms保存。确认保存状态，重要代码同时点击“导出代码”留副本；本机草稿不跨设备同步。
3. 核对“提交意图”后点击“提交代码”。服务端受理回执才表示已受理，最终正式/练习模式以服务端返回为准。当前若提示“提交服务尚未接入”，代码仍是草稿，没有成功提交记录。
4. 响应丢失时页面显示“核对上次提交”，再次操作会使用同一请求编号和原代码快照；不要把未知状态当失败并另造提交。频率限制时按页面倒计时手动重试。
5. B 结果组件接入后查看该提交结果和本轮固定帮助；“结果组件尚未接入”只说明有受理回执，不能推断判定或成绩。模型提示不会修改判定或成绩。

宽度小于600px时仅支持阅读题目和只读草稿，提交关闭；请在电脑编程。较窄桌面通过“题目/代码”页签切换。桌面分隔条可聚焦后用左右方向键调整；Tab 可离开代码编辑器。会话过期时先复制或导出当前代码，再重新登录；主动退出前按提示处理草稿。

## 5. 学生：错题、推荐与模型提示

“我的学习”或课程内“本课学习记录”显示个人内容。按“正式提交/练习提交”筛选错题；当前有效 AC 会移出对应类别待复习项，SE 不计为学生错题。推荐只显示当前可访问并已开放的练习，点击后仍会重新验证权限。

从错题点击“为此提交请求提示”，或填写本人提交 UUID。可先点“查看本轮固定帮助”，不必为固定帮助同意模型外发。只有已完成的 CE、WA、TLE、RE 提交适用模型提示。

补充可选问题，阅读并勾选代码外发同意，再点击“请求提示”。拒绝同意不会发出模型请求。服务端在受理、外发、生成完成和读取时复验当前权限与同族作业策略。READY 按“错误类别、定位线索、检查方向、学习建议”展示，建议需自行验证。可评价“有帮助/没有帮助/内容有误”，添加最多500字说明，保存后可修改。

PENDING 表示等待处理；FAILED 表示不可用；BLOCKED 表示当前策略限制。失败或受限时，如有授权的冻结固定帮助则显示该版本。不要用重复请求绕过限额或策略。次数、预算和队列限制以服务端提示为准，费用未知会保留预占，不能因超时就假定免费。

缺少 B 提交来源时，错题/推荐显示“暂不可用”；未启用模型或缺模板时请求被明确拒绝。这些状态不表示个人没有错题，也不表示模型已通过质量验收。公开练习题面当前提供阅读入口，独立练习提交仍需 B 接线。

## 6. 异常处理与验收边界

加载失败可使用页面“重试”。401重新登录；无权限或记录不存在时联系课程教师核对成员状态，勿尝试他人的编号；409先保留编辑并核对最新修订；503记录页面错误和请求编号，请管理员检查服务接线。不要把源码、隐藏测试或密钥粘贴到普通故障截图。

本指南不记录5名非开发者已完成验收，也不代替 A/B 独立模型评分。待真实参与者按[质量验收](07-quality-and-acceptance.md)完成教师备课、学生草稿恢复、错误提示理解、键盘/窄屏操作，并保留任务成功率、耗时、问题及复测；真实模型30例需实际两名评审分别评分并解决分歧。跨线闭环、课程容器与恢复验收另行记录。
